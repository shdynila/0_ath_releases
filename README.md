# 0ath Client Releases

Welcome to the public release repository for the **0ath Game Client**. 

This repository serves as the central hub for our community to:
1. **Download the Game:** Access the latest Alpha and Beta client binaries for Windows, macOS, and Linux.
2. **Read Patch Notes:** Stay up to date with new features, visual improvements, and bug fixes.
3. **Report Bugs:** Use the [Issues](../../issues) tab to report any glitches, crashes, or feedback you encounter while playing.

> **Note:** The source code for the game client and backend servers remains private. This repository is strictly for distribution and issue tracking.

## How to Play
1. Navigate to the [Releases](../../releases) tab.
2. Download the latest `.zip` file for your operating system.
3. Extract the contents to a folder.
4. Run `0ath_client` (or `0ath_client.exe` on Windows).
5. Login using your account credentials!

## System Requirements
* **OS:** Windows 10/11, macOS 11+, or Linux (Ubuntu 20.04+)
* **Graphics:** OpenGL 3.3 or Metal compatible GPU
* **Network:** Stable internet connection
